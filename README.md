# ORSO Uno Espresso Machine: Interactive 3D Exploded View

**Live demo:** https://2003nadiv-dot.github.io/coffee-demo/

Spin the machine, drag the slider to pull 18 parts apart, tap any part to learn what it does, look inside with X-ray, and switch between the Classic Steel and Midnight Copper designs. Works on phones and laptops.

ORSO is an original concept product made for this demo. It is not a real brand, and the specifications are illustrative.

Built with three.js by Nadiv A. Available for custom 3D product viewers on Upwork.
